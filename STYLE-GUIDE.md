# CausaVera Public Style Guide

## Direction

The public site should feel serious, calm, modern, analytical and executive-ready.

The Basewell reference supplied during design review is used only for presentation principles:
- large confident headline;
- generous white space;
- strong product visual;
- restrained interface;
- minimal clutter.

CausaVera must retain its own identity and messaging.

## Avoid

- hacker imagery;
- padlocks and generic shields;
- alarmist red dashboards;
- excessive gradients;
- visual noise;
- claims that outrun demonstrated product capability.

## Core narrative

Business Service → Systems → Applications → Controls → Obligations / Frameworks → Expected Evidence → Control Effectiveness → Business Impact / Risk

## Bilingual rule

English and French are equal publication versions. Layout changes must be synchronized across both versions.
