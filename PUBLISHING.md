# Bilingual Publication Workflow

## Website languages

- English is the default language at the root path.
- French is published under /fr/.
- Every major page should provide a direct EN / FR counterpart.

## PDF library

Approved article PDFs belong in:

```
public/pdfs/en/
public/pdfs/fr/
```

Recommended naming:

```
article-01-business-risk-intelligence-en.pdf
article-01-business-risk-intelligence-fr.pdf
```

## Release rule

Do not expose one language publicly while its paired version is still structurally out of sync.

For each article:

- [ ] English text approved
- [ ] French text approved
- [ ] English PDF visually checked
- [ ] French PDF visually checked
- [ ] Layout revision synchronized
- [ ] No overlaps or accidental blank regions
- [ ] Links verified
- [ ] EN / FR paired page verified

The current approved visual reference for Article 01 is the English v0.5 layout. Its French counterpart must receive the same structural corrections before the pair is released.
